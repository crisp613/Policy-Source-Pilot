## 正式接入建议

- 建议连接器类型：HTTP直采
- 建议访问频率：正式接入初期每天2次，单线程访问，后续依据稳定性复核
- 列表解析：服务端 HTML，解析 `.column-list li`
- 详情解析：分别解析摘要区、`.newsCon` 和 `.attachment`
- 增量依据：规范化详情 URL
- 主去重键：详情 URL 的 SHA-256
- 辅助去重键：`来源ID + 标题 + 发布日期`
- 更新判断：同一详情 URL 的标题、正文、日期、附件和办理入口内容哈希
- 失败退避：连接超时或5xx按60秒、5分钟、30分钟退避；出现403、412、429或挑战页面时停止本轮访问
- 监控字段：HTTP状态、最终URL、响应大小、响应哈希、列表数量、标题/日期/链接完整率、正文长度、附件数、登录提示和解析失败原因
