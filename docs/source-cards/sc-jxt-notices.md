## 初步建议

- 建议采集方式：普通 HTTP 获取服务端 HTML；列表与详情分开解析
- 建议访问频率：正式接入初期每天2次，单线程访问，具体频率在稳定性验证后复核
- 增量依据：规范化详情 URL；同一 URL 使用正文、附件和办理入口的内容哈希识别更新
