## 正式接入建议

- 建议连接器类型：HTTP直采
- 建议访问频率：正式接入初期每天1次，单线程访问，后续依据稳定性复核
- 列表处理：从外层页面发现并获取公开 iframe；解析服务端 HTML 表格
- 详情处理：只解析公开详情正文、受理时间、推荐时间、附件名称和官方入口
- 增量依据：规范化详情 URL
- 主去重键：详情 URL 的 SHA-256
- 辅助去重键：`来源ID + 标题 + 发布日期`
- 更新判断：同一详情 URL 的标题、日期、来源、正文、公开时间和附件名称内容哈希
- 失败退避：连接超时或5xx按60秒、5分钟、30分钟退避；出现403、412、429、登录挑战时停止本轮访问
- 监控字段：HTTP状态、最终URL、响应大小、响应哈希、iframe地址、列表数量、字段完整率、正文长度、登录提示和解析失败原因
