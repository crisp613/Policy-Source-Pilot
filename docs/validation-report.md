## 建议决策

### 可进入正式连接器设计候选

- 四川省经济和信息化厅：普通HTTP直采，列表和详情分开解析。
- 四川省科学技术厅：普通HTTP直采，保留空发布机构，不进入登录申报系统。
- 国家科技管理信息系统：普通HTTP获取公开iframe和公开详情，登录提示作为附件正文采集停止条件。

“进入设计候选”只表示字段和解析路径已经得到一次真实验证，不代表可以直接启用生产采集。

### 正式实现建议

- 三个来源均使用规范化详情URL的SHA-256作为主去重键。
- 使用 `来源ID + 标题 + 发布日期` 作为辅助去重键。
- 使用标题、正文、日期、附件和办理入口的内容哈希识别同URL更新。
- 四川省经信厅、省科技厅初期每日2次；国家科技管理信息系统初期每日1次。
- 单站单线程，维持低频访问。
- 连接超时或5xx按60秒、5分钟、30分钟退避；出现403、412、429、验证码或登录挑战时停止本轮访问。
- 持续监控HTTP状态、最终URL、响应大小、响应哈希、列表数量、字段完整率、正文长度、附件数、登录提示和解析失败原因。

### 提交或正式接入前必须补充

1. 为三个来源各完成一次成功的第二次真实运行。
2. 输出新增、重复、更新、当前样本缺失、访问失败和解析失败数量。
3. 复核响应哈希及运行记录与第二次快照一致。
4. 由负责人审核来源卡和本报告后，再在正式后端仓库的新分支中选择性迁移解析逻辑、字段定义和夹具测试。

当前不建议修改生产数据库、注册默认采集器或开启定时任务。
